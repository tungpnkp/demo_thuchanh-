# Bài 7.1 - Tính tổng tiền đơn hàng

**Kiến thức:** biến, phép tính, `echo`.

**Đề:** Sản phẩm "Bánh mì", đơn giá 15000, số lượng 3. Khai báo biến, tính thành tiền, VAT 10%, tổng tiền phải trả và in ra terminal.

**Kết quả:** Thành tiền 45,000 VNĐ - VAT 4,500 VNĐ - Tổng 49,500 VNĐ.

## Cách chạy (Terminal macOS / Linux / Windows)
```bash
cd đường-dẫn-tới/bai-7.1-php-tinh-tien-don-hang
php index.php
```
Kết quả được `echo` thẳng ra Terminal (không cần trình duyệt, không cần `php -S`).
Chưa cài PHP? Xem hướng dẫn cho [macOS](../HUONG-DAN-CHAY-PHP-MACOS.md) hoặc [Windows](../HUONG-DAN-CAI-PHP-MYSQL-WINDOWS.md).
