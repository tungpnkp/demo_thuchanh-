# Bài 7.2 - Đánh giá kết quả học viên

**Kiến thức:** `if / elseif / else`.

**Đề:** Với `$name = "Nguyen Van An"`, `$score = 7.5`: xếp loại (>= 8 Giỏi, >= 6.5 Khá, >= 5 Trung bình, < 5 Không đạt) và thông báo "Bạn đã đạt" / "Bạn chưa đạt".

Thử đổi `$score` thành 9, 6, 4 rồi chạy lại để kiểm tra từng nhánh.

## Cách chạy (Terminal macOS / Linux / Windows)
```bash
cd đường-dẫn-tới/bai-7.2-php-xep-loai-hoc-vien
php index.php
```
Kết quả được `echo` thẳng ra Terminal (không cần trình duyệt, không cần `php -S`).
Chưa cài PHP? Xem hướng dẫn cho [macOS](../HUONG-DAN-CHAY-PHP-MACOS.md) hoặc [Windows](../HUONG-DAN-CAI-PHP-MYSQL-WINDOWS.md).
