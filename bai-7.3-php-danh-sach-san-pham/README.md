# Bài 7.3 - Danh sách sản phẩm

**Kiến thức:** mảng, `foreach`, điều kiện.

**Đề:** Duyệt mảng `$products`, in từng sản phẩm kèm thành tiền, tính tạm tính, giảm 10% nếu tạm tính >= 100,000 VNĐ, in số tiền thanh toán.

**Kết quả:** Tạm tính 135,000 VNĐ - Giảm giá 13,500 VNĐ - Thanh toán 121,500 VNĐ.

## Cách chạy (Terminal macOS / Linux / Windows)
```bash
cd đường-dẫn-tới/bai-7.3-php-danh-sach-san-pham
php index.php
```
Kết quả được `echo` thẳng ra Terminal (không cần trình duyệt, không cần `php -S`).
Chưa cài PHP trên Mac? Xem [HUONG-DAN-CHAY-PHP-MACOS.md](../HUONG-DAN-CHAY-PHP-MACOS.md).
